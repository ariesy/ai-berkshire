## 第二步：生意本质分析 — 段永平"对的生意"

### 一句话定义

**长江电力是一门用"免费燃料（江水）+ 已建成顶级水电站"持续发电，卖给国家电网换取稳定现金流的"类债券"生意。**

### 生意本质拆解

**核心赚钱逻辑**：
1. 长江水是免费的（零燃料成本）
2. 六座世界级水电站已经建成（大部分折旧已过高峰期）
3. 发出的电按约定价格卖给国家电网/南方电网（零坏账风险）
4. 运营成本极低（主要是人工+维护+财务费用）
5. 现金流远高于净利润（折旧是账面非现金支出）

**关键数字**：
- 度电成本仅约 0.04-0.05 元/千瓦时（行业最低水平）
- 境内水电毛利率 65.79%（2025年）
- 经营现金流 605.63亿（2025年），是净利润的1.76倍
- 资产负债率 58.27%（逐年下降趋势）

### 商业模式画布

| 维度 | 特征 |
|------|------|
| 收入模式 | 电力销售（一次性消费，重复购买） |
| 客户粘性 | 极高——电网无替代供应商，刚性需求 |
| 燃料成本 | 零（江水免费） |
| 固定成本 | 折旧（逐步下降）+ 财务费用（逐步下降） |
| 边际成本 | 极低（多发电几乎不增加成本） |
| 再投资需求 | 低（水电站寿命超100年，无需大额维护） |
| 定价机制 | 政府指导价+市场化交易（价格稳定可预测） |
| 周期性 | 弱（电力需求稳定增长，与GDP正相关） |

### 5年盈利能力趋势

```
毛利率：57%→59%→59%→61%→62%（持续提升）
净利率：41%→39%→35%→38%→40%（2023年因资产注入有调整）
ROE：13%→12%→14%→15%→16%（持续提升）
```

### 段永平式追问

**Q：这门生意好在哪？**

A：好在"躺赚"——水是免费的、电站是已经建好的、客户（电网）不会跑路也不会赖账、价格有国家保护、需求只会增长不会下降。这是一门不需要聪明人管理也能赚钱的生意，好生意不需要天天做决策。

## 第三步：护城河评估 — 巴菲特"经济护城河"

### 五类护城河评估

| 护城河类型 | 强度 | 验证 |
|-----------|------|------|
| **资源垄断** | ⭐⭐⭐⭐⭐ | 长江干流水能资源不可复制，中国适合建大型水电站的坝址已开发殆尽 |
| **规模效应** | ⭐⭐⭐⭐ | 全球最大水电上市公司，度电成本4-5分，低于同行30%+ |
| **转换成本** | ⭐⭐⭐⭐⭐ | 电网不能换供应商——三峡电站是"西电东送"骨干电源 |
| **品牌/定价权** | ⭐⭐ | 水电同质化产品，定价依赖政府机制，但价格受保护 |
| **技术/专利壁垒** | ⭐⭐⭐ | 六库联调技术全球领先，节水增发电140亿度/年 |

### 护城河趋势分析

**过去5年**：护城河显著变宽。2023年完成乌东德、白鹤滩资产注入后，装机量从4,560万千瓦提升至7,170万千瓦（+57%），六库联调从"三库"升级为"六库"，调度效益倍增。

**未来5年预判**：护城河将继续维持甚至变宽——理由：
1. 资源稀缺性不可逆，无新竞争对手能建同等规模水电站
2. 折旧逐步到期（三峡左岸/右岸/地下机组），成本进一步下降
3. 抽水蓄能业务打开第二增长曲线
4. 财务费用随债务偿还持续下降

### 什么能摧毁护城河？

- **极端气候改变长江径流模式**（如持续干旱）——可能性存在但概率低
- **技术颠覆**（如小型核聚变）——10年内不可能
- **电价市场化改革大幅压低电价**——是最大风险，但央企地位可缓冲

### 巴菲特式追问

**Q：10年后这条护城河还在吗？**

A：10年后不仅还在，而且更宽。因为：① 竞争对手10年内同样无法在长江干流上建水电站（已无合适坝址）；② 折旧再减少3-5年，成本更低；③ 电力需求10年后只会更大。唯一能削弱护城河的是电价政策大幅变化，但央企决定了这种变化的幅度有限。

### 历史类比

长江电力最接近的类比不是其他中国水电公司，而是：
- **金罗斯黄金（Kinross Gold）** 般的资源垄断生意——但长江电力的"矿"不会枯竭
- **铁路公司（如BNSF/Berkshire拥有的）** ——都拥有不可复制的物理基础设施+稳定的现金流
- **特许经营公用事业**——但长江电力的"许可证"是自然资源本身，不会到期

### 空方核心论点

1. **增长见顶论**：装机容量已到天花板（无新大型水电站可建），未来收入只能靠来水和电价波动
2. **利率风险论**：低利率环境推高了水电估值，若利率上行，"类债券"属性会变成劣势
3. **来水不确定性**：2022年已验证极端天气可导致发电量下降30%+
4. **电价下行风险**：电力市场化改革持续推进，水电高电价面临回归

**对空方论点的回应**：
- 增长=收入增长的狭义理解是错误的——盈利增长可来自成本下降（折旧到期+财务费用压降）
- 长江电力的估值溢价不仅是"类债券"——更是对"低协方差"资产的重估（与市场波动的相关性极低）
- 电价确实有下行压力，但幅度有限（央企+西电东送）且可通过电量增长部分对冲

### 芒格式追问

**Q：我最可能在哪里犯错？**

A：最可能的错误是高估了"确定性"的价值——当市场恐慌时，"确定性"值很多钱；但市场亢奋时，它会重新变得平庸。如果A股进入全面牛市，长江电力的相对收益会跑输。另一个可能是过于乐观地认为电价永远不会大幅下跌——电力市场化改革的不确定性比大多数分析认为的要大。

## 第六步：行业与文明趋势 — 李录"文明演进框架"

### 行业定位

水电行业处于**成熟期**，但正在经历从"基荷电源"向"系统调节主力"的角色转换。

### 行业核心趋势

1. **电力需求持续增长**：2025年全国用电量10.37万亿度（+5%），预计2026年增5-6%。AI算力、新能源汽车等新需求驱动
2. **水电的"调峰价值"上升**：风光装机高速增长（2025年占60%装机但电量仅~30%），电网稳定性需求增加，水电调峰价值重新定价
3. **水电开发已见顶**：全国水电装机4.5亿千瓦，可经济开发的资源已开发殆尽。存量资产=稀缺资产
4. **抽水蓄能迎来爆发**：是水电公司最自然的第二增长曲线
5. **电价市场化改革深化**：长期趋势，但对水电影响可控

### 历史技术革命类比

长江电力在能源转型中的角色类似**20世纪初的铁路公司**——基础设施已经建成，需求只会增加，竞争不会出现。不是"这个时代的标准石油"（标准石油代表了高增长+高竞争），也不是"昙花一现的3Com"（过时技术），而是"拥有永久特许经营权的收费桥梁"。

### TAM与增长天花板

| 维度 | 现状 | 天花板 |
|------|------|--------|
| 水电主业 | 3072亿度发电量 | 装机已见顶，未来增长有限 |
| 电价提升 | 280元/兆瓦时 | 温和通胀+市场化可能小幅提升 |
| 成本压缩 | 折旧+财务费用下行 | 折旧2030年后基本到后期 |
| 抽水蓄能 | 在建+规划 | 新增长点，但不能与主业体量相比 |
| 国际业务 | 秘鲁为主 | 贡献有限（占总资产~10%） |

### 李录式追问

**Q：站在20年后回看，长江电力是"这个时代的标准石油"还是"昙花一现的3Com"？**

A：都不是。它更像是"中国能源基础设施的永久持有者"——一个不会过时、不会被替代、需求只会增长的永续生意。20年后长江电力大概率依然存在，赚的钱比现在多（通胀推高电价+折旧到期释放利润），但成长速度不会快于GDP增速。
