## 前置步骤：AI研究偏见自觉

### 信息丰富度评级：A级（信息充裕）

白酒行业是A股研究覆盖最密集的板块之一，茅台、五粮液等权重股有数十家券商覆盖。ETF本身信息公开透明（规模、净值、持仓均可从天天基金、上交所等获取）。行业层面有毕马威/酒业协会联合发布的中期报告、高盛研报、多家券商月度跟踪。

**AI研究陷阱**：
- **共识过强**：当前市场对白酒"深水调整期"的叙事高度一致，AI容易输出与市场无差异的分析
- **情绪传染**：大量负面报道（86.7%企业利润下滑、68.5%预期继续下行）会引导AI过度悲观
- **周期误判**："底部区域"的判断可能受"抄底"叙事影响，低估可能持续更久

**偏见自查清单**：
- [x] 我的"确定性"感受是来自生意本质，还是来自资料数量？→ 来自大量资料，需警惕
- [x] 如果把这家公司的资料量减少一半，我的结论会变吗？→ 不会，核心逻辑在于白酒的生意本质
- [x] AI输出的分析是否与市场共识高度雷同？→ 大概率是，需主动寻找反共识视角
- [x] 是否存在"公开资料很少但生意本质极好"的可能性被低估了？→ 不适用，白酒是高度公开的行业

**AI研究局限性声明**：正因信息充裕，本报告的分析可能与市场共识高度趋同。读者的信息优势不在于"知道什么"，而在于"敢不敢在极度悲观时下注"以及"对周期拐点的判断是否比市场更准"。

## 一、重要说明：512690跟踪的是"中证酒指数"而非"中证白酒指数"

**关键事实**：512690（鹏华中证酒ETF）跟踪的是**中证酒指数（399987）**，而非**中证白酒指数（399997）**。

| 维度 | 中证酒指数（399987） | 中证白酒指数（399997） |
|------|---------------------|---------------------|
| 成分股数量 | 27只 | 17只 |
| 覆盖范围 | 白酒+啤酒+葡萄酒 | 纯白酒 |
| 纯白酒股占比 | ~90% | 100% |
| 主要差异成分股 | 青岛啤酒、燕京啤酒、重庆啤酒、百润股份、古越龙山等 | 无 |
| 前十大集中度 | ~78% | ~88% |
| ETF跟踪产品 | **512690（鹏华酒ETF）** | 161725（招商中证白酒LOF） |

**影响评估**：由于白酒股在中证酒指数中权重占比约90%，两个指数走势高度相关。但啤酒/葡萄酒股的长期回报低于白酒，纯白酒指数历史表现更优。用户俗称的"中证白酒ETF"实为"酒ETF"，分析时以中证酒指数为准，同时参考中证白酒指数作为对照。

## 五、白酒行业基本面趋势

### 行业周期定位：深水调整"磨底"阶段

| 阶段 | 时间 | 特征 |
|------|------|------|
| 高景气周期 | 2016-2021 | 量价齐升，茅台批价突破3000元，行业利润高速增长 |
| 调整初期 | 2022-2024H1 | 去库存开始，增速放缓，渠道杠杆收紧 |
| 调整深水区 | 2024H2-2025 | 行业营收利润双降，茅台批价从2950跌至2400以下 |
| **当前** | **2026H1** | **"量价利三杀"尾声，边际改善信号出现，底部区域确认** |

### 2026年上半年核心数据

| 指标 | 数据 | 趋势判断 |
|------|------|---------|
| 规上白酒产量（26Q1） | 95.2万千升，同比-1.7% | 降幅收窄（2025年同期-7.2%） |
| 20家上市酒企营收（26Q1） | 1,326亿元，同比-0.7% | 接近持平（2025全年-18.1%） |
| 20家上市酒企净利润（26Q1） | 520亿元，同比-1.75% | 降幅大幅收窄（2025全年-24.1%） |
| 飞天茅台批价/月均工资 | 约28%（2021年60%高点→当前28%） | 性价比改善，低于2013年水平 |
| 酒企预期下半年继续下行 | 68.5% | 悲观预期主导，但已Price-in |

### 关键趋势

1. **消费理性化**：86.4%企业观察到消费理性化趋势，"面子消费"→"里子消费"
2. **场景迁移**：商务礼赠→日常刚需；社交驱动→悦己为主
3. **价格带下移**：次高端（300-800元）和中端（100-300元）成为竞争主战场
4. **头部集中加速**：茅台+五粮液+泸州老窖占规上企业利润超54%
5. **低度化/年轻化**：五粮液推出29度"一见倾心"（上市2月销售额破亿），光瓶酒市场突破2000亿
6. **渠道去库存**：经销商库存正逐步回落至合理区间，头部企业主动控量稳价

### 机构观点汇总

| 机构 | 核心观点 |
|------|---------|
| 高盛 | "复苏极早期，已出现企稳信号"，最坏时刻已过 |
| 华创证券 | 端午动销局部拐点初显，下半年低基数下有望转正 |
| 浙商证券 | 26Q2起业绩有望由负转正，进入底部拐点区间 |
| 招商证券 | 25Q4为最深调整单季，26Q1降幅已收敛 |
| 中泰证券 | 加速筑底，头部酒企一季度边际改善 |
| 毕马威/酒协 | "悲观者占多数，乐观者缺信心"的预期低谷期 |

**行业整体判断**：行业共识是"底部已近，但全面复苏仍需时日"。2026年下半年有望在低基数下实现营收增速转正，但强复苏概率低，预计为弱复苏/结构性复苏。

## 六、生意本质分析（段永平"对的生意"）

### 一句话定义

白酒生意本质 = **高毛利、强品牌、不折旧的社交货币生产商**。

### 核心特征

| 维度 | 特征 |
|------|------|
| 毛利率 | 高端>85%，次高端>70%，全行业平均>60% |
| 经营杠杆 | 极高——固定成本占比低，增量利润几乎全部转化为净利 |
| 资产特征 | **越放越值钱**（基酒陈化增值），不折旧反升值 |
| 现金流 | 先款后货（经销商预打款），经营现金流极强 |
| 复购驱动 | 社交场景刚需（宴请/礼赠）+ 成瘾性（酒精）+ 品牌习惯 |
| 库存性质 | **老酒增值**，不同于一般消费品（库存减值风险极低） |
| 护城河类型 | 品牌+文化+工艺+渠道，四维复合护城河 |

### 段永平式追问

> **"这门生意好在哪？如果只能用一句话描述，是什么？"**

**答**：白酒是极少数"产品不折旧、客户不流失、定价权强、现金流好"的完美生意。高端白酒本质上是"社交货币+成瘾消费品+可储存投资品"的三位一体。茅台批价从3000跌到2200，依然是全球最赚钱的饮料企业——这本身就说明了护城河的宽度。

## 七、护城河评估（巴菲特"经济护城河"）

### 护城河五维验证

| 护城河类型 | 验证 | 评分 |
|-----------|------|------|
| **品牌/定价权** | 茅台2025年逆势提价、五粮液控量挺价能力仍在 | ⭐⭐⭐⭐⭐ |
| **转换成本** | 商务宴请场景品牌不可替代（茅台就是茅台），很难用江小白替代 | ⭐⭐⭐⭐⭐ |
| **网络效应** | 弱——喝酒的人越多并不直接让酒更好喝（但品牌共识有网络效应） | ⭐⭐⭐ |
| **规模效应** | 头部酒企产能/渠道/品牌投入的规模优势显著，小酒企难以追赶 | ⭐⭐⭐⭐ |
| **技术/专利壁垒** | 工艺壁垒（窖池不可复制、勾兑技艺），但非技术密集型 | ⭐⭐⭐ |

**综合护城河评级**：**宽（Wide）**——在消费品行业中属于最顶级水平。

### 巴菲特式追问

> **"10年后这条护城河还在吗？什么能摧毁它？"**

**答**：10年后白酒的护城河大概率还在，但具体形态可能变化。真正的风险不是竞争对手，而是：
1. **代际消费断层**：年轻人喝白酒的比例持续下降（目前85后/90后仍是白酒消费主力，但95后/00后偏好低度酒/洋酒）
2. **禁酒令升级**：2025年新禁酒令冲击政务场景（已基本归零），若蔓延至商务场景则冲击更大
3. **人口结构**：白酒主力消费群体（40-60岁男性）规模在人口老龄化下逐步收缩

## 八、逆向思考与风险清单（芒格"反过来想"）

### 失败路径分析

| 路径 | 概率 | 影响程度 | 描述 |
|------|------|---------|------|
| 代际消费断层加速 | 中等 | 高 | 年轻人彻底抛弃白酒，转向葡萄酒/威士忌/精酿/预调酒 |
| 宏观经济持续低迷 | 中高 | 中高 | 商务宴请和礼赠场景萎缩超预期，行业利润持续下滑 |
| 政策监管加码 | 中低 | 高 | 限制白酒广告/提高消费税/扩大禁酒范围 |
| 渠道库存崩盘 | 中低 | 中高 | 经销商资金链断裂，被迫低价抛货，摧毁价格体系 |
| 茅台批价失控 | 低 | 高 | 茅台批价跌破出厂价（目前仍远高于出厂价），动摇全行业价格锚 |
| 食品安全黑天鹅 | 极低 | 极高 | 如塑化剂事件重演（但当前监管和品控已大幅提升） |

### 芒格式追问

> **"我最可能在哪里犯错？聪明人为什么会不买/做空这家公司？"**

**答**：我最可能犯的错误是**"估值陷阱"**——认为PE低=值得买，但白酒可能面临的是永久性的需求萎缩（类似2013年后的香烟销量持续下降）。聪明人不买的理由：代际消费断层不可逆，这轮调整不是周期性的，而是结构性的。

**空方核心论点**：
1. 白酒总量从2016年1358万千升降至2025年354.9万千升（-74%），趋势不可逆
2. 高盛预计2030年行业销量仅能恢复至2024年的75%
3. 年轻消费者对白酒的偏好系统性降低
4. 商务消费在宏观经济承压下持续走弱
