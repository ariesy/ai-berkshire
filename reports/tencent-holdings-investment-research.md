## 第二步：生意本质分析 — 段永平"对的生意"

### 一句话定义

**腾讯是一门"社交关系链×数字内容×金融科技"的三位一体生意**——通过微信/QQ掌握14亿人的社交关系，以此为管道分发游戏、广告、支付和企业服务。

### 收入结构演变

```
收入占比变化（FY2021 → FY2025）:
VAS（游戏+社交）:  63% → 49%  ↓ 降依赖
广告:              13% → 19%  ↑ 高增长
金融科技/企业:     20% → 31%  ↑ 第二曲线
```

**关键变化**：腾讯正从"游戏公司"转型为"平台型公司"。广告和企业服务占比从33%提升到50%，收入多元化显著改善。

### 5年盈利能力趋势

```
毛利率:   43.9% → 43.1% → 48.1% → 52.9% → 56.2%  (↑ 12.3pp)
经营利润率: 22.1% → 20.0% → 26.8% → 31.5% → 32.7%  (↑ 10.6pp)
ROE:       ~20% 水平（FY2025: 20.14%）
```

**毛利率从43%飙升至56%**，4年提升12个百分点——这不是周期性的，而是结构性的。原因：
1. 高毛利广告业务占比提升（广告毛利率58% vs VAS 60% vs 金融科技51%）
2. 游戏业务国际化的高利润率贡献（国际游戏毛利率>国内）
3. 降本增效后运营杠杆释放

### 商业模式画布

| 维度 | 描述 |
|------|------|
| **收入模式** | 混合型：游戏内购（一次性+持续消费）+ 广告（流量变现）+ 金融（交易抽成）+ SaaS订阅 |
| **客户锁定** | **极强**——微信社交关系链不可迁移，切换成本接近无穷大 |
| **复购驱动** | 游戏靠内容更新+社交驱动复玩；支付靠习惯+生态绑定；广告靠流量增长 |
| **边际成本** | 接近零——数字内容分发边际成本极低，规模效应极强 |

### 段永平式追问

> **这门生意好在哪？如果只能用一句话描述，是什么？**

**"微信是中国数字生活的操作系统"**——14亿人每天打开微信，不是为了某一个功能，而是因为所有人都在上面。这个入口价值是任何单一产品都无法替代的。游戏是利润引擎，微信是护城河本身。

## 第三步：护城河评估 — 巴菲特"经济护城河"

### 五类护城河逐一验证

| 护城河类型 | 强度 | 验证依据 |
|-----------|------|---------|
| **品牌/定价权** | ⭐⭐⭐⭐ | 微信品牌不可替代；游戏IP（王者荣耀、LOL）有定价权；但广告定价受字节跳动竞争 |
| **转换成本** | ⭐⭐⭐⭐⭐ | **最强护城河**——微信社交关系链（14亿人）无法迁移。切换到其他社交App = 放弃所有社交关系 |
| **网络效应** | ⭐⭐⭐⭐⭐ | **最强护城河**——微信的网络效应是教科书级别的：用户越多→生态越丰富→更多用户加入。小程序、支付、视频号都建立在这个网络之上 |
| **规模效应** | ⭐⭐⭐⭐ | 全球最大游戏公司（按收入），规模带来研发/运营/分发成本优势；支付业务的规模效应 |
| **技术/专利壁垒** | ⭐⭐⭐ | 混元AI大模型有一定技术壁垒，但AI领域竞争激烈；自研芯片紫霄提供硬件差异化。整体技术壁垒弱于社交关系链壁垒 |

### 护城河趋势

**过去5年**：护城河**显著变宽**
- 毛利率从43%升至56%——定价权在增强
- 广告业务从13%升至19%——生态变现效率在提升
- 国际游戏突破$100亿——从中国公司变为全球公司
- AI大模型（混元）+微信AI Agent——新增AI护城河层

**未来5年预判**：护城河将继续变宽
- 微信AI Agent（负一屏语音助手）可能重新定义超级App交互范式
- 国际游戏继续扩张（Level Infinite品牌已建立）
- 云业务首次盈利后进入增长期

### 巴菲特式追问

> **10年后这条护城河还在吗？什么能摧毁它？**

**10年后护城河大概率仍在。** 能摧毁它的路径：
1. **出现全新的社交范式**（如元宇宙/AR社交取代手机社交）——概率低，微信有Meta系投资和视频号布局
2. **强制拆分**（政府要求微信独立运营）——中国当前政策方向不支持
3. **大规模数据泄露/信任危机**——概率低但影响极大
4. **美国制裁升级**（禁止全球使用微信）——概率低，微信主要是中国用户

### 空方核心论点

1. **AI军备竞赛吞噬利润**：2026年AI投入>360亿，Q1资本开支319亿（+63% QoQ），短期看不到AI回报
2. **广告增长见顶**：视频号流量增速放缓（+20% vs 前几年+50%），字节跳动仍是最大对手
3. **估值不便宜**：虽然PE 15x看似低，但包含6,727亿投资组合价值，剔除后核心业务PE可能只有10-12x——但也可能意味着投资组合被低估
4. **地缘政治尾部风险**：美国制裁名单是悬在头上的剑

### 芒格式追问

> **我最可能在哪里犯错？聪明人为什么会不买/做空这家公司？**

最可能犯错的地方：**高估了微信的不可替代性**。如果年轻一代转向抖音作为"主要社交平台"（抖音已有私信/社交功能），微信的社交垄断地位可能被缓慢侵蚀。空方的核心逻辑是：微信是"基础设施"但不是"增长引擎"。
