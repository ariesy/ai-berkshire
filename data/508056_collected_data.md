## 12. 核心优势

| 优势 | 说明 |
|------|------|
| 先发优势 | 中国"首发+扩募"双首批REITs，上交所首支仓储物流REIT |
| 规模优势 | 资产数量最多（10个）、规模最大、区域覆盖最广 |
| 运营商能力 | 普洛斯是全球仓储物流龙头，运营实力不可复制 |
| 分红稳定性 | 连续分红16次，累计超15亿元，历年分配比例≈100% |
| 租户多元化 | 无单一租户>10%，五大租户仅25%收入占比 |
| 行业周期拐点 | 供需关系改善（净吸纳>新供）、出租率止跌回升 |
| 安全边际 | 价格较NAV折价~24.5%，处于历史低位区间 |
